SHAGGY VS GOKU — FREE GITHUB PAGES WEBSITE

Files:
- index.html: the website
- screenshot.jpg: the screenshot displayed on the page

To publish for free with GitHub Pages:
1. Sign in to GitHub and create a new PUBLIC repository named shaggy-vs.
2. Upload index.html and screenshot.jpg to the repository root (not inside another folder).
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose the main branch and / (root), then Save.
6. Wait for GitHub Pages to publish. The public URL will be https://YOUR-USERNAME.github.io/shaggy-vs/

No custom domain or paid hosting is required. Keep both files in the same folder in the repository.
